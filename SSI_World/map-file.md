# map-file

Loads a map file kept in scriptfiles, so a map is changed without touching the gamemode. A map file is the lines a mapping tool writes: `CreateObject`, `CreateDynamicObject`, `SetObjectMaterial`, `SetObjectMaterialText`, `RemoveBuildingForPlayer` and `AddSimpleModel`.

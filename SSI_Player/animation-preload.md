# animation-preload

Animation libraries loaded ahead. The game loads an animation library the first time one of its animations is played, and that first animation does not play. The libraries given to `PreloadAnimationLibrary` are loaded on the first spawn of each player, so the first animation a script plays shows like the others. Bots of the server are left out.

# extra

Extra data: values kept on the ids of something else, with a row of cells for each id and a column for each name. A column has a type, which is a number, a float, a boolean or a string, and a default. Reading or writing a number is an array index. Columns are made by name in a hook of `OnExtraInit`, and every id starts with the default of each column.
